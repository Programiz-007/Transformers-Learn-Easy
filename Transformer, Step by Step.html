Transformer, Step by Step

Follow one sentence through a real transformer, from words to a guess at the next word. Every number on this page is computed live in your browser by a tiny model with 1 layer, 2 attention heads and 8 numbers per word. It was trained on 88 short sentences about cats, dogs and birds.

01

Split the text into tokens

A transformer can't read letters. First the text is cut into tokens, and each token is replaced by its number in a fixed vocabulary. This model knows 28 words, and each word is one token. GPT-2 knows 50,257 tokens, many of them pieces of words such as ing.

Click a token to make it the focus token. Steps 3 to 6 show the details for that token.

02

Turn each token into a vector

Each token ID picks one row from the embedding table: a list of 8 numbers the model learned in training. Words that are used the same way end up with similar rows.

Attention looks at all the words at once, so it has no sense of order on its own. A positional encoding, a fixed pattern of sine and cosine waves, is added so that “the” at position 0 and “the” at position 3 look different.

xi = Embedding[tokeni] + PositionalEncoding(i)

03

Make a query, key and value

Each token now makes three new vectors by multiplying its input x by three learned matrices.

Query: what this token is looking for. Key: what this token offers. Value: the information it passes on to whoever pays attention to it. Each head has its own three matrices, and here each one makes 4 numbers per token.

Q = x·WQ    K = x·WK    V = x·WV
04

Attention: who looks at whom

Every query is compared with every key. The better a match, the more that token's value flows into the result. Walk through the four steps:

Attention(Q, K, V) = softmax( Q·KT / √dk + mask ) · V

Rows: query token. Columns: key token. Click a row.

05

Several heads, side by side

The model runs 2 heads at the same time, each with its own weights, so each can follow a different relationship. Compare where each one looks. Their outputs are joined (4 + 4 = 8 numbers) and mixed by one more matrix, WO.

MultiHead = [ head1 | head2 ] · WO
06

Add & norm, then feed-forward

Residual connection: the attention output is added to the original input, so the token keeps what it had and gains context from other words. Layer normalization then rescales the 8 numbers to an average of 0 and a spread of 1, which keeps training stable.

Feed-forward network: each token then goes through the same small network on its own. It expands to 16 numbers, sets the negatives to zero (ReLU), and shrinks back to 8. Attention moves information between tokens; the feed-forward network processes it inside each token.

h = LayerNorm(x + Attention(x))    out = LayerNorm(h + W2·ReLU(W1·h + b1) + b2)

Together these steps make one transformer block. This model has 1 block. GPT-2 small stacks 12, each feeding its output into the next.

07

Predict the next word

Only the last token's final vector is used to guess what comes next. It is multiplied by an output matrix, which gives one score (a logit) for each of the 28 words. Softmax turns the scores into probabilities.

Temperature divides the scores before softmax: below 1 makes the top word win more often, above 1 spreads the chances out. Top-k keeps only the k most likely words before picking one at random.

P(next word) = softmax( (hlast·WU + b) / temperature )

About this model

The model was trained on every sentence a small grammar can make, such as “a happy dog ran in the park.” and “the cat drank the milk.” It learned that the word after “the dog chased the” is “ball” but after “the cat chased the” it is “mouse”. To get that right it has to look back at the animal, which is exactly what attention is for.

The computation is the same as in a real transformer. Only the sizes are different:
